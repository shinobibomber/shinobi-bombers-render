# Website generator

`website/` is the published website and the visual source of truth. Its behaviour lives in hand-edited files:
`website/app.js`, `app.css`, `cm.js`, `cm.css` (Chest dashboard) and `website/game-link/` (game connection).
Edit those directly for behaviour or style changes.

The screen artwork (`website/assets/*.webp`) and the embedded screen data (hotspots, live-text boxes, effects) in
`website/index.html` are generated by the Python scripts here from your reference screenshots.

## Regenerate screens (only needed when reference art or hotspot positions change)

Requirements: Python 3.11+, `pip install pillow numpy scipy`.

```bash
export SB_UPLOADS=/path/to/your/uploaded/screenshots     # 1793481009081_image.png, fusion_uploaded_reference.png, …
export SB_UPDATE_PACK=/path/to/extracted/Updates           # the extracted Updates.zip design pack
python3 website-src/build.py      # writes website/assets/* and website/data.json
python3 website-src/assemble.py   # embeds data.json into website/index.html
npm run test:visual               # compare every screen against the tagged baseline
```

Rebuilding from the same inputs reproduces the current files byte-for-byte (verified during the integration).

| File | Purpose |
| --- | --- |
| `spec.py` | Screen list, hotspot rectangles and actions per screen |
| `build.py` | Crops/patches the reference art, exports WebP assets and screen data |
| `header_controls.py` | Wallet pill + Ryo "+" hotspots and live-text boxes used by the game link |
| `patch_header_data.py` | Adds those header controls to an existing build without regenerating art |
| `assemble.py` | Writes `data.json` into `index.html` |
| `cm-base.*`, `app_new.js` | Original sources the current `cm.*`/`app.js` were assembled from (reference only) |
| `detect.py`, `det2.py`, `draw*.py` | Helpers used to locate and visually check hotspot coordinates |
